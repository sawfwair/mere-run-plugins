Third-party notices for Archive Tools
====================================

This file preserves notices for AnyDoc 0.2.4 and its pdf-inspector 1.14.2
component. The mere-archive-tools package installs firecrawl-anydoc as a
separate dependency. It does not vendor the dependency's source or binaries.

These notices supplement, rather than replace, the licenses and notices for
other dependencies. This file is not a complete dependency license inventory.

all applicable notices. Update this file when the reviewed licenses change.
